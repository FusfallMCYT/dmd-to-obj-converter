# dmd-to-obj-converter
Converts DMD to OBJ model.

This Program converts DMD (ZDSimulator) to OBJ model.

What he can: Analyse DMD Model, Convert it to OBJ, Rename Model after converting, Set texture to model after converting.

P.S. Program was maden by ChatGPT and Gemini and it can not work with other DMD Files (not ZDSimulator)
